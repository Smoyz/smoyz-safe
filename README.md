# Smoyz Safe

Encrypted personal vault: passwords, bank cards, and money notes. All data stays on the user's device, encrypted with AES-256-GCM — no server, no accounts.

- Web app: `index.html`
- Android APK: `SmoyzSafe.apk` (download page: `download.html`)
- Update manifest for the in-app updater: `version.json`
